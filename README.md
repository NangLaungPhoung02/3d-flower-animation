# 🌸 3D Flower Animation

A Three.js project created while learning 3D graphics and particle systems.

## 🚀 Technologies

- Three.js
- JavaScript
- Vite
- HTML
- CSS

## 📦 Installation

```bash
npm install
```

## ▶️ Run

```bash
npm run dev
```

Open:

```
http://localhost:5173
```
stop the server 
Start: npm run dev
Stop: Ctrl + C

## 🎯 Learning Goals

- Learn Three.js
- Build 3D animations
- Create particle systems
- Recreate a rotating flower animation
